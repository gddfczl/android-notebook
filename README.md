# 安卓记事本 (Android Notebook) - v1.0

[![Release](https://img.shields.io/github/v/release/gddfczl/android-notebook)](https://github.com/gddfczl/android-notebook/releases)
[![Platform](https://img.shields.io/badge/platform-Android-green.svg)](https://www.android.com)

一款简洁、现代且高度可定制的安卓记事本应用。采用 Material 3 设计规范，专注于为您提供纯净的速记体验。

A simple, modern, and highly customizable Android notepad application. Built with Material 3 design principles, focusing on providing a pure and efficient note-taking experience.

---

## 🌟 主要功能 (Key Features)

### 🎨 深度自定义色彩系统 (Deep Color Customization)
- **12 种精选配色**：预设 12 种莫兰迪色系底色，视觉舒适，护眼美观。
- **分类与色彩解耦**：您可以为每个分类自由指定 12 种底色中的任意一种。
- **自由增删分类**：默认精简为 3 个常用分类，支持根据个人需求无限扩展或删除。

### 🚀 极简交互体验 (Minimalist Experience)
- **移除冗余状态栏**：删除了应用内模拟的状态栏，完美适配安卓原生顶栏，视野更开阔。
- **实时搜索过滤**：支持关键词全文搜索，并可按颜色分类快速筛选笔记。
- **智能排版**：支持宫格 (Grid) 与列表 (List) 两种视图切换，满足不同审美偏好。

### 🔒 纯净安全 (Clean & Secure)
- **无打扰设计**：没有任何推送提醒和后台广告，专注记录。
- **本地存储**：数据存储在设备本地，安全可靠。
- **快速复制**：一键点击即可复制笔记全文到剪贴板。
